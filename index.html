Per display: Settings › Personalization › Background › Picture, right-click an image › “Set for monitor N”. Spanned: pick “Span” as the fit. Span needs each display’s Windows X/Y in native pixels — Detect displays fills them in.

Banding? Windows recompresses wallpapers to ~85% JPEG. Turn that off, then sign out and back in: reg add "HKCU\Control Panel\Desktop" /v JPEGImportQuality /t REG_DWORD /d 100 /f
